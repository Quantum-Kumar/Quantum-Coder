# Quantum Error Correction Simulations

**Languages/Libraries:** Python, STIM, Qiskit

## Overview
This project involves simulating Surface Code, Steane, and Toric Code circuits using STIM and Qiskit under realistic circuit-level noise models.

## Key Highlights
* Built syndrome extraction and decoding workflows using Minimum Weight Perfect Matching (MWPM) to estimate logical error rates across multiple code distances.
* Performed Monte Carlo simulations to study fault-tolerance thresholds and the impact of measurement noise on logical qubit fidelity.
