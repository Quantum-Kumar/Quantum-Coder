# Hamiltonian Learning & Adaptive Calibration

**Framework:** Iterative Adaptive Spectroscopy (IAS)
**Languages/Libraries:** Python, QuTiP, Qiskit Dynamics

## Overview
This project involves developing Iterative Adaptive Spectroscopy (IAS) routines for extracting Hamiltonian parameters from time-evolution data under realistic noise conditions.

## Key Highlights
* Designed automated calibration workflows to estimate spectral leakage and optimize measurement settings, reducing convergence time to fewer than 8 iterations.
* Utilized Fisher-information-based optimization to improve parameter estimation efficiency.
