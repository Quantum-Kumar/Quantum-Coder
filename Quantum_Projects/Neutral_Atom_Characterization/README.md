# Neutral Atom Characterization

**Hardware/Platform:** QuEra Aquila (Amazon Braket)
**Languages/Libraries:** Python

## Overview
This project focuses on executing Analog Hamiltonian Simulation (AHS) programs on QuEra’s Aquila neutral-atom processor using Amazon Braket. 

## Key Highlights
* Measured second-order correlation functions ($g^{(2)}$) to study spatial correlations and Rydberg blockade behavior in programmable atom arrays.
* Built Python analysis pipelines to process JSON measurement outputs and compare experimental results against theoretical simulations.
* Investigated discrepancies between measured and simulated data to study noise and calibration drift effects.
