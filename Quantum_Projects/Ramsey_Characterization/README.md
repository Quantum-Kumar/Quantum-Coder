# Ramsey Characterization

**Hardware/Platform:** IBM Quantum Hardware
**Languages/Libraries:** Qiskit, OpenPulse

## Overview
This project implements Ramsey pulse sequences on IBM superconducting qubit backends to estimate $T_1$ and $T_2$ coherence times and monitor calibration drift.

## Key Highlights
* Modeled driven qubit dynamics using Qiskit Dynamics to study pulse-level gate errors and effective Hamiltonian behavior under realistic control conditions.
