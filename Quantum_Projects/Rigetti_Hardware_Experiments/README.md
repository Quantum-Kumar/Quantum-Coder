# Rigetti Hardware Experiments

**Hardware/Platform:** Cepheus-1-108Q (Amazon Braket)
**Languages/Libraries:** Python

## Overview
This project involves running Rabi oscillation and Ramsey interferometry experiments on the Rigetti Cepheus-1-108Q superconducting quantum processor through Amazon Braket.

## Key Highlights
* Prepared Bell states.
* Analyzed hardware noise behavior by comparing measured results with simulation predictions.
